# 📊 HR Analytics Dashboard (Power BI)

Interactive HR Analytics Dashboard built using Power BI to analyze employee attrition, workforce demographics, and HR KPIs.

## 🎯 Problem Statement
Employee attrition directly impacts productivity and hiring costs. This dashboard analyzes HR data to identify attrition trends, department-wise patterns, and workforce demographics to help HR teams make data-driven retention decisions.

## 📁 Dataset
- HR employee records including: Age, Department, Job Role, Monthly Income, Years at Company, Attrition status, and more
- Source: IBM HR Analytics Employee Attrition dataset

## 🔍 Key Insights
- Analyzed overall employee attrition rate across departments
- Identified departments and job roles with highest attrition
- Explored relationship between age, income, and attrition
- Visualized workforce demographics (gender, age groups, tenure)

## 🛠️ Tools Used
- **Power BI** — Data modeling, DAX measures, interactive visuals
- **Excel** — Initial data cleaning

## 📌 How to View
1. Download the `.pbix` file from this repository
2. Open it in Power BI Desktop to explore the interactive dashboard
